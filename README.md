# 烛阴旧闻：项目入口

这是一款以“失踪朋友沈妍的电脑”为主要操作界面的中文论坛调查游戏。目标首次游玩时长约 2 小时，核心循环是：

**阅读真实材料 → 获得自然关键词/人物 → 搜索或查看历史 → 跨论坛/微信/本地资料互证 → 玩家自己形成解释。**

## 唯一现行世界观依据

从 2026-08-19 起，后续开发只以这一份总集作为世界观与剧情依据：

> **`docs/CANON_v3.0_世界观与游戏设定唯一权威集.md`**

- 无相真君、候舍制度、α/β/γ、19-07、周川/折柳、三结局等最后修订。

旧 CANON 和旧流程文件继续留在仓库中用于追溯素材来源，但**不再作为并列开发依据**。如果旧文档与 v3.0 冲突，以 v3.0 为准。

## 开发纪律

1. 世界观有新决定时，必须同步回写 v3.0，不再长期堆碎片 CANON；
2. 如果代码与 v3.0 冲突，先判断是新决定还是遗留 bug，再同步两边；
3. 旧材料只要符合现逻辑就优先复用，不为同一功能另造第二套术语/经文/人物；
4. 每轮实际代码或权威文档修改完成后记录 commit SHA。
