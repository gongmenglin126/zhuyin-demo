# 烛阴旧闻：项目交接说明

这是一款以“失踪朋友的电脑”为唯一主要操作界面的中文论坛调查游戏。目标首次游玩时长约 2 小时，核心循环是：**阅读真实材料 → 获得自然关键词/人物 → 搜索或查看用户历史 → 跨论坛/微信/本地资料交叉验证 → 玩家自己形成解释。**

## 当前必须遵守的固定事实

- 玩家为**徐宁**；失踪朋友为**沈妍**。
- 徐宁与沈妍从**小学低年级**就认识，不是初一相识。
- “候鸟第七年”就是沈妍本人，不做账号身份谜题。
- 故事开端真实状态为 A+β：沈妍身体中是原林楠之魂；β 已作为沈妍真实生活十多年，不是“冒牌朋友”。
- 林楠童年旧居与梦境稳定细节有关：**红铁皮盒**、右侧褪色蓝窗帘、朝走廊开的厨房门等。
- “易舍”只能发生在两个活体之间，且是双向交换；不是单向夺舍或死者复活。
- 《百舍偈》固定可辨认句为：**“身非我身，名非我名”**。
- 《三门疏》核心真句包括：**“形可易，名可夺，忆可乱；客不可凭一门自证。”**
- YQ = **余晴**；她是现实外围引诱者，不需要论坛核心身份。
- **周川 = 折柳**；同一人，长期监督者。
- **梁茵 = 迟迟**；同一人，真实受害者/善意联系人。
- **照骨** = 无相还真会共享监测账号，不对应某一个微信联系人。
- 只保留三个结局：《双归》《归还》《故门有声》。

## 当前信息通道规则

### 论坛

负责公开痕迹：旧帖、旧报、回复历史、长期账号行为、普通人的真实经历。

### 微信

负责现实关系：沈妍和谁熟、谁知道她查到哪里、失踪前见了谁、同一人物私下怎么说。

核心跨平台对应只保留真正有叙事价值的两组：

- 周川 ↔ 折柳
- 梁茵 ↔ 迟迟

不要把所有论坛账号都塞进微信，也不要给余晴硬造论坛小号。

## 当前早期调查链

基准顺序：

1. 梦境帖出现“楠楠”、**红铁皮盒**和稳定房间结构。
2. 从红铁皮盒相关帖子/评论进入**一格胶片**主页。
3. 找到《分享一组岚棉三厂旧址的窗户照片》。楼主必须是一格胶片，候鸟第七年只是评论追问。
4. 三厂老住户自然提到当年楼下贴过**寻人启事**。
5. 玩家搜索自然词“寻人启事”，找到普通旧论坛回忆帖。
6. 帖中“报刊索引”提到自己整理过当年地方报。
7. 玩家点“报刊索引”的公开发言历史，找到标题不直接泄露姓名的旧报摘录。
8. **林楠**第一次在旧报正文中出现；此时“楠楠 → 林楠？”才成为玩家自己的关联。

禁止要求玩家输入“2004 九岁 姓林”“岚棉三厂 走失”这类数据库式组合搜索。

## 当前两层密码结构

旧 `0407` / 版号拼密码流程已经废弃。

### 本地资料

- 只保留一个干净的加密入口。
- 密码：**红铁皮盒**（4 个汉字）。
- 提示必须像沈妍给自己看的私人提示；当前基准为“打开前会卡一下”。
- 解开后得到《百舍偈》，其中出现“身非我身，名非我名”。

### 论坛私密第一层

- 候鸟第七年的个人主页可看见私密主题入口。
- 密码：**林楠**（2 个汉字）。
- 第一层只包含沈妍的调查记录、案例共性、原始异常；不能直接宣布“换魂”。

### 第二层机制材料

- 只有进入“林楠”解开的第一层后，才出现 8 个汉字密码附件（如 `archive_0712.zip`）。
- 玩家把之前得到的“身非我身名非我名”用于这里。
- 第二层才允许出现：舍 / 客 / 形名忆 / 二客 / 两门 / 再舍 / 故门等机制词。

因此：**查到林楠 ≠ 查到灵魂互换。** 灵魂互换必须由玩家把旧案对应关系和宗教机制材料拼起来之后自己提出。

## 微信材料交互规则

- 不是所有材料都能发。
- 不是所有材料都能发给所有人。
- 玩家必须从已取得、且对当前联系人合理开放的材料中**主动选择要发送哪一份**。
- 能发送不代表对方一定回复；已读、沉默、敷衍或延迟回应都可以成立。
- 周川主要接收旧报、案例对照、经文等需要核验的材料。
- 梁茵主要接收与她经历、身份错位、同类受害者、相关术语有关的材料。
- 余晴只承担现实行程/见面语境，不做深层经文问答。
- 方嘉、爸妈、徐宁自己的对话不提供调查材料发送入口。

## 体验硬约束

- 沈妍不知道自己会被抓，不得写给徐宁的遗书、教程或“如果你看到这里”。
- 论坛约 95% 是普通用户。评论必须像活人，不能集体神神叨叨。
- **帖子和搜索结果从一开始客观存在。变化的是玩家知道该搜什么、终于看懂什么；不是论坛替玩家推进剧情。**
- 不设计“线索自动解锁”；优先设计“搜索词/理解被解锁”。
- 事实层尽量全部真实；错误或不完整主要发生在人物解释层。
- 没有垃圾假线索，只有真实但不一定属于同一答案的信息。
- 不弹系统总结替玩家推理，不用“证据已足够”。
- 普通电脑界面不要做证据板、任务面板或上帝视角流程提示。
- 坏结局只能在后期由“泄露精确入口/核心真相 + 独自赴约 + 未形成有效报警保护”共同触发；早期发普通材料、正常调查、报警都不能偷判失败。

## 核心易舍机制（防漂移）

- 第一次易舍前：A+α（原沈妍）、B+β（原林楠）。
- 第一次易舍后：A+β 回到沈妍家庭；B+α 回到林楠家庭。
- 第二次再易引入 C+γ（γ 为主动信徒）；B+α 与 C+γ 交换后形成 B+γ、C+α，A+β 暂时保持不动作为远端观察对象。
- α 再次移动会重新触发/强化 α—β 旧契，使 A+β 出现远端回流；这些是**β 自己作为林楠的童年记忆**，不能写成“原沈妍记忆”。
- 返契用于稳定/强化/控制旧契，不等于再做一次完整换魂。
