# 烛阴旧闻：项目交接说明

这是一款以“失踪朋友的电脑”为唯一主要操作界面的中文论坛调查游戏。目标首次游玩时长约 2～3 小时，核心循环是：阅读正常内容、从材料取得明确关键词、搜索隐藏旧帖、比对现实资料，再逐步进入旧后台与现实地点调查。

`烛阴旧闻_世界观唯一权威设定档_v2.0.docx`

- 沈妍最后自愿行动为 2026-10-16 20:10 在河临北站西广场北侧落客区与余晴见面。
- 沈妍 2004-07-17 失踪，2004-07-30 在河临南站附近被找回，共十三天。
- 林楠 2004-07-18 在岚棉三厂家属区失踪；两人于 2004-07-20 完成第一次易舍。

- 现实据点为岚州市东浦区北堤路 17 号；主楼 17 号-1，前台楼 17 号-2。不得重新使用静修院、栖真院等旧名。
- 只保留三个结局：《双归》《归还》《故门有声》。

- 候鸟第七年的八篇公开主题按发布时间从早到晚排列；
- 旧房手绘图、岚棉三厂照片、户型图和既有电子材料；
- 正文证据词原位加粗，图片点击放大；
- 首页不可见、只能通过明确关键词搜索到的旧帖；
- 双钥匙私密存档流程：
  1. “河临晚报索引”只保留两条事件记录，以及“两个版号，按失踪—找回顺序”的自然备注；
  2. 通过浏览记录中的“沈妍 2004 失踪”搜索回到论坛隐藏旧报，取得 `04版`、`07版`；
  3. 打开本地资料中锁定的“缓存页”；连续输错后只提示先对照索引与论坛版号；
  4. 输入 `0407` 解锁缓存页；
  5. 打开其中唯一的《百舍偈》缓存链接；
  6. 浏览器直接呈现黑纸红字残页，不提供无实际用途的扫描切换按钮；从图中辨认“身非我身，名非我名”；
  7. 在八个汉字格中输入口令；
  8. 进入论坛账号内的三篇私密主题。
- 八格输入属于论坛自身界面，不再用一篇站务帖解释 UI；
- 私密存档改为论坛个人中心中的私密主题列表与单帖阅读页。
- 私密主题中的《三门疏》图片使用沈妍自己的圈注，只表达她当时的疑问，不把猜测写成真相。

私密存档目前是第二阶段开头。管理员账户、真假案例组、三名联系人完整互动、第一次/第二次易舍材料、现实地点互证和三个结局尚未全部实现。

## 体验硬约束

- 沈妍不知道自己会被抓，不得写给徐宁的遗书、攻略或“如果你看到这里”。
- 论坛约 95% 是普通用户。评论必须像活人，不能集体神神叨叨。
- 搜索词必须来自玩家已经读到的人名、日期、机构名、账号、编号或原文术语。
- 私密存档、隐藏帖和附件只能增加可读材料，不能弹出系统总结替玩家推理。
- 调查文件夹未来只保存原文件、来源与时间，不写注解、不自动连线。
- 管理员后台必须制作成真实可交互网页，已有 JPG 只能作为视觉参考。
- 坏结局只能由晚期“泄露精确入口＋独自赴约＋未有效报警”共同触发，不能在早期偷判失败。

## 开发与构建

关键文件：

- `app/page.tsx`：桌面、论坛、微信、本地资料阅读器、异常经文页与交互；
- `content/gameData.ts`：帖子、回复、聊天、浏览记录和私密主题数据；
- `app/globals.css`、`app/game.css`：界面样式；
- `public/assets/`：已确认可复用的图片素材；
- `scripts/build-single-page.mjs`：生成可直接双击运行的单文件 HTML。

常用命令：

```bash
npm ci
npm run lint
npm run build:pages
npm run build:single
```

`npm run build` 仍依赖已经移除的 ChatGPT Sites `.openai/hosting.json`，不用于当前 GitHub Pages/单文件交付。不要为了让旧测试假绿而伪造该配置。
