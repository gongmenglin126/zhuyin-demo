# 《烛阴旧闻》CANON v2.3 易舍机制与纸人验证玩法修订

状态：**权威修订**  
生效日期：2026-08-17

> 本文件覆盖 v2.2 中涉及“名可夺 / 定名 / 名不随客 / 管理员还真验门”的机制与玩法描述。与 v2.2、v2.1、v2.0 冲突时，以 v2.3 为准。

## 1. “名”退出易舍物理机制

易舍真正涉及的核心只保留：**舍（身体） / 客（灵魂） / 忆（交换后的残留、混乱与重建）**。

删除以下机制：
- 名可夺；
- 名不随客；
- 名字跟身体或灵魂移动的规则；
- 定名符作为易舍必要步骤；
- 管理员验证中的“守原名 / 随客易名”。

姓名只是现实社会对一具身体及其既有身份的称呼。易舍后，家人、户籍、照片和生活环境仍会让外界沿用这具身体原有的姓名，不需要超自然规则解释。

## 2. “身非我身，名非我名”的定位

**身非我身，名非我名**继续保留，但它不是技术规则。

它表达的是易舍者最直观的身份错位体验：身体陌生，别人叫自己的名字也产生“不像在叫我”的感觉。它可以作为无相还真会旧誓/宗教表达存在。

《三门疏》机制句修订为：
- 身为舍，魂为客；
- **形可易，忆可乱；**
- 二客相契，两门相应；
- 再舍者，故门有声。

旧版“形可易，名可夺，忆可乱”废止。

旧版“赤烛照舍，黄符定名”废止；如旧教材料需要对应短句，改为：**赤烛引客，黄符镇舍。**

## 3. 管理员兼容认证：旧誓之后不再讲宗教话语

玩家仍需先在旧档认证中主动录入旧誓“身非我身，名非我名”。

旧誓通过后的交互验证不再显示“舍身无量”“旧客退位”等仪式台词，也不再把验证做成经文阅读理解。验证本身应像一个来源不明、非常诡异的旧网页小游戏。

## 4. 第一关：两个纸人归入两个家

- 页面出现两个带夸张微笑的纸人。
- **纸人本体不写“林楠 / 沈妍”。房间也不写姓名。**
- 两个纸人只保留可从旧报推断身份的日期戳：`07·18` 与 `07·17`。
- 两个房间用生活细节区分，例如：三厂 4 栋的蓝窗帘/红铁皮盒，与青梧旧楼的红发卡/奶糖罐。
- 这些归属关系必须由前面论坛帖子、旧报和个人旧帖自然提供。谜题页面不能替玩家写答案。
- 玩家必须手动拖动两个纸人进入对应房间。
- 放错不会推进；放对后该纸人的夸张笑容消失，变成无表情。
- 两个纸人均正确归位后自动进入第二关，不显示“恭喜/第一关成功”。

## 5. 第二关：桌上分物

桌面出现 5 件可拖动物品：

- 林楠侧：**话梅糖、蓝玻璃弹珠**；
- 沈妍侧：**奶糖、红色发卡**；
- 共享物：**红铁皮盒**。

交互反馈：
- 普通物放对：纸人收下，物品留在其手边；
- 普通物放错：纸人撇嘴，物品回到桌面；
- 红铁皮盒拖给任意一个纸人：**两个纸人都会同时伸手**，但都不能单独收下；
- 玩家把红铁皮盒放回两人中间时，两边同时伸手按住它；
- 四件普通物全部正确归属 + 红铁皮盒位于中央，才算通过。

页面不出现解释“为什么两个人都记得”之类的作者文字。玩家只需要先产生疑问。

## 6. 线索散布原则

分物答案不能集中在一篇答案帖中。至少分散到不同类型的自然材料：
- 林楠的话梅糖：三厂家属区旧住户闲聊；
- 林楠的蓝玻璃弹珠：另一篇童年玩具闲聊；
- 沈妍的红色发卡：旧寻人启事衣着栏；
- 沈妍的奶糖：候鸟第七年的普通旧帖；
- 红铁皮盒：继续通过梦帖、旧房照片、本地资料等多处反复出现，不提前解释其“双向反应”。

难度来自“我之前在哪里见过这个”，不是来自隐藏按钮，也不是靠谜题页面给提示。

## 7. 视觉与反馈

- 纸人初始笑容必须明显且不自然；
- 第一关归位后笑容消失；
- 第二关错误反馈使用轻微撇嘴，不弹系统报错；
- 红铁皮盒触发两个纸人同步伸手，是本关最重要的异常视觉反馈；
- 不使用跳脸；不使用“验证正确/错误”的大字覆盖；
- 整体仍可保留旧纸、暗红、蜡烛残光等邪教视觉，但**玩法过程中不朗诵宗教话语**。
