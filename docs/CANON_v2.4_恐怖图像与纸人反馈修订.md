- `assets/occult/recovered-ritual-v904.webp`：两个纸偶、红烛、黄符、红线、灰烬与暗色污迹的旧仪式现场；
- `assets/occult/recovered-talisman-v904.webp`：黄纸符页局部恢复图；
- `assets/occult/huanzhen-scripture-v904.webp`：黑底朱字旧教页；
- `assets/occult/recovered-redbox-v904.webp`：红铁皮盒、纸偶、红烛与黄符的恢复照片。

目标感受是“现实里真的有人做过这种仪式”，不是“网页在给玩家画邪教图标”。

## 2. #23109 失效附件

帖子《老帖附件只恢复出黄纸和两个纸人，有人认得吗》保留“失效附件 → 第一次读取失败 → 点击重试”的过程。

重试成功后：

1. 直接显示 `recovered-ritual-v904.webp`，作为恢复帧 01；
2. 再显示 `recovered-talisman-v904.webp`，作为黄纸局部裁切的恢复帧 02。

页面只提供技术性的恢复说明，例如“原图缺损 / 色彩偏移 / 局部裁切”。不要在图片旁替玩家解释仪式含义。

## 4. 管理员回收记录

## 5. 删除“纸人伸手”反馈

第二关分物中，任何情况下纸人都**不能伸手、长出胳膊或做抢东西动作**。

共享物“红铁皮盒”的反馈改为：

- 拖给林侧：林侧保持无表情，**沈侧纸人短暂恢复第一关那种不自然的笑**；
- 拖给沈侧：沈侧保持无表情，**林侧纸人短暂恢复不自然的笑**；
- 物品不被任何一侧单独收下，仍回到桌面；
- 拖到两人中间：两边都恢复无表情，红铁皮盒停在中央，**盒盖轻微翘开**；
- 四件普通物全部归属正确 + 红铁皮盒在中央，才通过第二关。

这个异常只通过画面表现，不出现“这是共享记忆”“两个人都想要”之类解释文字。

## 6. 纸人视觉

互动纸人仍可用网页绘制以支持拖拽，但必须降低卡通感：

- 纸张边缘不规则；
- 头部不要圆润玩偶化；
- 眼睛更像墨画出的窄黑痕；
- 笑容僵硬、像人为画上去；
- 第一关归位后笑容消失；
- 第二关普通物放错时可以轻微撇嘴；
- 红铁皮盒错误归边时使用“另一只重新笑”的异常反馈。

不要使用 emoji、卡通手臂、可爱动作或夸张弹跳。
