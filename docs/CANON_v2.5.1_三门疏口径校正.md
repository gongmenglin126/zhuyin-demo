# 《烛阴旧闻》CANON v2.5.1 《三门疏》口径校正

状态：**权威修订**  
生效日期：2026-08-19

> 本文件只校正 `CANON_v2.5_无相真君候舍制度与终局修订.md` 对《三门疏》个别句子的错误拆分。其他 v2.5 内容继续有效。

## 1. 《三门疏》必须作为一套完整材料理解

《三门疏》不是若干个彼此独立的宗教理论模块。

现行已确认文本继续以 v2.3 为准：

> **身为舍，魂为客。**  
> **形可易，忆可乱。**  
> **二客相契，两门相应。**  
> **再舍者，故门有声。**

玩家应当通过这组句子整体建立对易舍的理解：

- 舍 / 客是什么；
- 两个对象为什么需要形成对契；
- 两端为什么会互相产生反应；
- 同一个客发生再舍后，旧对契为什么仍可能出现梦境、记忆和情绪回流。

不要把“故门有声”等半句独立升级成一个新的后台模块、理论名、功能名或额外谜题。

## 2. 对 v2.5 的覆盖

`CANON_v2.5` 中以下写法废弃：

- 把“故门有声”拆成独立教义系统；
- 把玩家的旧推理词单独扩写成一套新的正式术语；
- 为这些句子另造后台页面、分类或机制名。

保留的是它们表达的**既有剧情现象**，而不是新增术语体系。

## 3. 旧教文本与现代后台如何对应

旧教材料保持原貌，不需要管理员逐句翻译。

玩家后期自己能够对应：

- `二客相契，两门相应` ↔ 后台 **对契 / 匹配度**；
- `再舍者，故门有声` ↔ 后台 **再舍完成后旧对契同步异常 / 记忆回流**；
- `形可易，忆可乱` ↔ 沈妍、19-07 的身份与记忆混乱。

这种对应关系可以通过不同材料互相印证，但 NPC 和系统都不要替玩家做完整翻译。

## 4. 旧资料复用原则不变

此前已经使用过、且玩家能够顺利推理的《三门疏》相关帖子、经文、纸人、符咒、门形视觉、红线、梦境与管理员记录继续保留。

本轮只纠正命名方式，不废弃既有线索和玩法。
