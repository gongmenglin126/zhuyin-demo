# 《烛阴旧闻》CANON v2.5.1 《三门疏》口径校正

状态：**权威修订**  
生效日期：2026-08-19

> 本文件校正 `CANON_v2.5_无相真君候舍制度与终局修订.md` 对《三门疏》及旧图线索的误记。其他 v2.5 内容继续有效。

## 1. 《三门疏》必须作为一套完整材料理解

《三门疏》不是若干个彼此独立的宗教理论模块。

现行已确认文本继续以 v2.3 为准：

> **身为舍，魂为客。**  
> **形可易，忆可乱。**  
> **二客相契，两门相应。**  
> **再舍者，故门有声。**

玩家应当通过这组句子整体建立对易舍的理解：

- 舍 / 客是什么；
- 两个对象为什么需要形成对契；
- 两端为什么会互相产生反应；
- 同一个客发生再舍后，旧对契为什么仍可能出现梦境、记忆和情绪回流。

不要把“故门有声”等半句独立升级成一个新的后台模块、理论名、功能名或额外谜题。

## 2. 对 v2.5 的覆盖

`CANON_v2.5` 中以下写法废弃：

- **“故梦有声”这一写法全部废弃。正确文本始终是“再舍者，故门有声”。**
- 把“故门有声”拆成独立教义系统；
- 把玩家旧推理词单独扩写成一套新的正式术语；
- 为这些句子另造后台页面、分类或机制名。

保留的是它们表达的既有剧情现象，而不是新增术语体系。

## 3. 旧教文本与现代后台如何对应

旧教材料保持原貌，不需要管理员逐句翻译。

玩家后期自己能够对应：

- `二客相契，两门相应` ↔ 后台 **对契 / 匹配度**；
- `再舍者，故门有声` ↔ 后台 **再舍完成后旧对契同步异常 / 记忆回流**；
- `形可易，忆可乱` ↔ 沈妍、19-07 的身份与记忆混乱。

这种对应关系可以通过不同材料互相印证，但 NPC 和系统都不要替玩家做完整翻译。

## 4. 旧图中的对契原句必须保留

此前玩家已经使用并能顺利推理的旧图原句为：

> **同庚同辰，乃天定之契。**

这是正确原句，应保留。

`CANON_v2.5` 中误写、扩写出的“同根同气”不再作为本作正式固定术语；除非旧素材原图本身已有该文字，否则不要新增“同根同气”来替代玩家已经熟悉的线索。

“同庚同辰，乃天定之契”承担的是**早期对契筛选的宗教化表达**：

- 让玩家在旧材料阶段意识到无相还真会会刻意寻找条件高度接近的两个人；
- 与2004年沈妍/林楠这一对儿童样本形成印证；
- 后期再与管理员后台的“对契 / 匹配度”形成自然对应。

它不必被解释为所有年代、所有易舍都必须严格同年同月同日。现代组织已经把筛选扩展成更复杂的匹配系统，因此成年候舍制度与该旧句不冲突。

## 5. “门”、符咒、纸人等旧材料继续复用

此前已经使用过、且玩家能够顺利推理的以下材料继续保留：

- 《三门疏》完整四句；
- `同庚同辰，乃天定之契`；
- 门形印记、两门、验门；
- 黄符、赤烛、红线、纸偶；
- 梦境、旧屋、旧称呼、记忆回流；
- 管理员对契、匹配度、再舍、同步异常记录。

其中黄符继续采用 v2.3 之后的口径：

> **赤烛引客，黄符镇舍。**

不恢复已废弃的“黄符定名”。

本轮只纠正原句和命名方式，不废弃既有线索和玩法。
