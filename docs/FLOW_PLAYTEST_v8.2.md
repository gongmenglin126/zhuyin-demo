# v8.2 论坛流程试玩

本轮验证目标：玩家通过真实论坛功能与逐步获得的关键词推进，而不是系统解锁新线索。

前段自然链路：

1. 候鸟第七年的梦境帖：注意“楠楠”、固定房间结构等加粗词。
2. 候鸟第七年主页 / 浏览记录：进入岚棉三厂旧址帖子。
3. 老住户回复提供“2004 年”“孩子走失”“姓林”等信息，但不给完整姓名。
4. 玩家自行搜索“岚棉三厂 2004 失踪”等组合，找到林楠旧报。
5. 对照电脑里沈妍自己的 2004 年旧报，注意年龄、日期、失踪时长。
6. 再以“2004 7月 九岁 失踪”等事实词搜索，找到 2010 年旧闻考据帖。
7. 此时合理的第一解释仍可为同一流窜团伙；后续经文与身份异常材料再迫使玩家修正模型。

规则：事实层尽量真实；误导来自解释与错误关联。旧帖从一开始存在，不因玩家进度凭空出现。
