## 必须继承的制作原则

- 玩家是徐宁；失踪朋友是沈妍。不要再写成徐妍、许妍或其他旧名。
- 沈妍不知道自己会遭遇什么，不能留下给徐宁的遗书、教程或“如果你看到这里”。
- “候鸟第七年”就是沈妍，不做身份证明谜题。
- 私密口令固定为“身非我身，名非我名”，不是“名非我命”。
- 论坛约 95% 应是普通人正常聊天；不要让评论区集体神神叨叨。
- 关键词必须是玩家已经读到的明确人名、日期、账号、地点、版号或原文术语，不能写成谜语。
- 不弹出系统总结替玩家推理，不用“证据已足够”之类上帝视角提示。
- 调查文件夹只整理原文件、来源和时间，不自动连线、不写结论。
- 管理员后台必须做成真实可交互网页，不能用一张后台 JPG 代替。
- 坏结局只能在后期由“泄露精确入口、独自赴约、未有效报警”共同触发；徐宁不知道自己已经暴露。
- 只保留三个结局：《双归》《归还》《故门有声》。

## 此前踩过的坑

- 早期 Demo 过度简化，论坛不像论坛、文本量不足、层层递进不够。
- 曾把大量线索一开始堆给玩家，导致瞎点也能连续解锁；后续必须按阅读与搜索自然推进。
- 曾使用顾澜/听潮等已废弃人物口径。现以 CANON v2.0 中的余晴、周川/折柳、梁茵/迟迟、照骨为准。
- 曾把坏结局写成早期直接质问或立刻暴露；现已废弃。
- 曾把经文密码写错成“身非我身，名非我命”；现已纠正。
- 曾把私密存档做成突兀面板、把管理员界面做成图片；后续都应保持论坛帖/真实网页形态。
- 视觉素材尽量采用电子页面和可控文字排版；图片内需要精确中文时谨慎使用生成图。

## 本地开发

进入 `03_源码/zhuyin-demo-v8` 后执行：

```bash
npm ci
npm run lint
npm run build:pages
npm run build:single
```

当前 `npm run lint` 与 `npm run build:pages` 已验证通过。`npm run build` 依赖已移除的旧 ChatGPT Sites 配置，不作为本项目当前发布命令。
