## 必须继承的制作原则

- 玩家是徐宁；失踪朋友是沈妍。不要再写成徐妍、许妍等旧名。
- 徐宁与沈妍从**小学低年级**认识，不是初一。
- 沈妍不知道自己会遭遇什么，不能留下给徐宁的遗书、教程或“如果你看到这里”。
- “候鸟第七年”就是沈妍，不做身份证明谜题。
- 核心物件正式关键词是**红铁皮盒**；普通叙述可说“红色盒子”“那个盒子”等。
- 论坛第一层私密口令为**林楠**；八字经文用于第一层之后出现的第二层附件。
- “身非我身，名非我名”属于《百舍偈》；不是“名非我命”。
- 周川 = 折柳；梁茵 = 迟迟；余晴不需要论坛核心账号；照骨是组织共享监测账号，不对应单一微信联系人。
- 论坛约 95% 应是普通人正常聊天；不要让评论区集体神神叨叨。
- 搜索词必须来自玩家已经读到的自然人名、原句、账号、地点或事件词；禁止作者视角的数据库式组合搜索。
- 林楠应该是玩家在旧报正文中**读出来**的名字，不是提前输入的答案。
- 帖子和搜索结果从一开始客观存在；变化的是玩家知道该搜什么以及终于看懂什么，不是论坛替玩家“解锁线索”。
- 不弹出系统总结替玩家推理，不用“证据已足够”等上帝视角提示。
- 调查材料只保留原内容、来源与时间；不自动连线、不写结论。
- 微信不是万能问答器：只有特定材料能发给特定联系人，且发送不等于必定回复。
- 管理员后台必须做成真实可交互网页，不能用一张后台 JPG 代替。
- 坏结局只能在后期由“泄露精确入口/核心信息 + 独自赴约 + 未形成有效报警保护”共同触发。
- 只保留三个结局：《双归》《归还》《故门有声》。

## 当前人物口径

### 跨论坛 / 微信

- **周川 = 折柳**：长期监督者。论坛上理性、证据导向；微信里是沈妍已建立信任的现实联系人。
- **梁茵 = 迟迟**：真实受害者/善意联系人。公开区与现实身份必须保持谨慎边界。

### 现实微信为主

- **余晴（YQ）**：外围引诱者；负责现实信任、见面和失踪前行程。不需要额外论坛小号。

### 论坛为主

- **照骨**：组织共享监测账号，不对应具体微信联系人。
- **一格胶片**：普通旧建筑/摄影用户。
- **三厂老住户**：普通旧住户。
- **报刊索引**：旧报资料用户。

新增 NPC 前必须先问：**能不能复用现有人物？**

## 易舍机制防漂移

- 第一次易舍前：A+α（原沈妍）、B+β（原林楠）。
- 第一次易舍后：A+β 回到沈妍家庭，B+α 回到林楠家庭。
- 第二次再易引入 C+γ；B+α 与 C+γ 交换后为 B+γ、C+α，A+β 暂时不动。
- α 再次移动重新触发/强化 α—β 旧契，使 A+β 出现远端回流；这些是 β 自己作为林楠的童年记忆，不得写成“原沈妍记忆”。
- 返契是稳定/强化/控制旧契，不是再做一次完整换魂。
