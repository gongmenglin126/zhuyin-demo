# 第一部：游戏本体与叙事原则

## 1. 核心 premise

玩家是 **徐宁**。

失踪的人是徐宁从**小学低年级**认识至今的朋友 **沈妍**。

徐宁来到沈妍住处，通过沈妍仍保持登录状态的电脑调查她为什么失踪。

主要操作空间始终是这台电脑：

- 浏览器 / 烛阴旧闻论坛；
- 微信；
- 本地资料；
- 浏览器缓存；
- 后期管理员后台；
- 三个结局。

目标首次游玩时长约 2 小时。

核心循环：

> **读材料 → 得到自然关键词/人物 → 搜索或查看历史 → 跨论坛/微信/本地资料互证 → 玩家自己形成解释。**

## 2. 体验硬约束

- 沈妍不知道自己会被抓，不能留下给徐宁的遗书、教程或“如果你看到这里”；
- “候鸟第七年”就是沈妍，不做账号身份谜题；
- 论坛约 95% 像普通大型民俗/旧闻论坛，普通用户说正常人话；
- 帖子和搜索结果从一开始客观存在，变化的是玩家知道该搜什么、能看懂什么；
- 不用系统弹窗替玩家总结真相；
- 不做普通电脑里的证据板、任务树或自动连线；
- 事实层尽量真实，错误和不完整主要来自人物理解；
- 没有纯垃圾假线索，可以有真实但暂时无关的信息；
- 难度来自跨材料理解，不来自隐藏按钮或数据库式关键词；
- 新增 NPC 前先问：**现有人物能不能承担这个功能？**

### 2.1 宗教露出与后台回访

- 公共论坛首页允许出现少量**表面是普通地方旧俗、实际与无相还真会教义同构**的帖子；前期不直接点名组织，不把论坛写成邪教群聊；
- 管理员后台增加“**诵录**”入口，用宗教日课形式呈现固定祝号与现行研究目标；
- 后台可明确：**真君无相，不应有定身**；现阶段的技术目标是验证同一客可在多具舍之间连续迁移并尽量保持记忆与主体连续，从而建立可重复的换舍路径；
- 仍不回答无相真君的原始身份、是否为同一古老魂、或是否只是宗教职位；
- 管理员后台内部提供“返回论坛”入口；首次成功登录后只记住账号 `旧档员-03`，**不保存密码**。再次进入时玩家只需自行输入 `gumen-0712`；若忘记，可重新走旧档兼容认证小游戏取得口令。

# 第二部：人物唯一口径

## 3. 徐宁

- 玩家本人；
- 与沈妍从小学低年级认识；
- 2026 年调查沈妍失踪；
- 只有坏结局《双归》中才被组织控制并进行易舍；
- 玩家调查时不知道玩家认识的“沈妍”身体中的客已经不是 2004 年原始沈妍。

## 4. 沈妍 / 候鸟第七年

“沈妍”必须区分**身体/社会身份**与**客**。

### 4.1 身体 A

身体 A 是沈妍的原始身体，社会身份始终叫沈妍。

### 4.2 客 β

2004 年后身体 A 中的客为 **β**，β 的原始登记身份是林楠。

从 2004 到 2026，β 一直以“沈妍”身份生活、成长、与徐宁相处。

因此玩家认识的朋友沈妍，在心理和社会关系上就是这个生活了二十多年的人，**不能把她简单写成“冒牌货”**。

她 2026 年出现的旧屋、红铁皮盒、“楠楠”等记忆回流，本质上是 β 自己作为童年林楠时的记忆被旧对契重新激活。

## 5. 林楠

身体 B 是林楠的原始身体。

- 2004 易舍后：B + α；
- α 在 B 中稳定生活约 22 年；
- 2026-10-12 再舍后：B + γ。

因此 2026 再舍以后，**林楠身体中的人是客 γ**。γ 是 19-07 原客，也是主动候舍信徒。

所以林楠身体不能再承担“被困受害者求救”功能。

## 6. 19-07

19-07 是现代成年候舍库中的候舍对象。其原身体记为 C，原客为 γ。

2026-10-12 与林楠身体中的 α 进行再舍：

- 执行前：B + α；C + γ；
- 执行后：B + γ；C + α。

执行后的 19-07 即 **C + α**。

其状态不是“清醒保存完整记忆的原沈妍”，而是严重身份混乱：

- 在“沈妍 / 林楠 / 登记身份”之间反复；
- 能说出不属于当前身体的旧屋细节；
- 听到“徐宁”产生强烈情绪反应，但可能反问她是谁；
- 可能在某个瞬间坚称自己是“沈妍”，下一刻又无法确认；
- 核心恐怖句：**“我以前长什么样？”**

因此《归家》里的陌生好友申请可以出现“我是沈妍”，但必须理解为身份混乱中的一次自我认定，而不是作者宣布“她才是真沈妍”。

## 7. 周川 = 折柳

同一人。

- 论坛身份：折柳；
- 微信身份：周川；
- 无相还真会长期监督者；
- 前期理性、可靠、证据导向；
- 他的“可靠”本身就是长期监控的一部分。

现行揭露方式：

1. 管理员操作记录出现来源“折柳”；
2. 玩家主动回论坛搜索“折柳”；
3. 折柳公开资料页显示实名资料“周川”；
4. 微信才解锁“你是折柳？”；
5. 周川被揭露后彻底敌对，不再承担分析 NPC；
6. 玩家查到 `HL-N-04` 后，周川直接威胁不要报警、一个人来。

核心语气：

> **我就是在威胁你。**

## 8. 梁茵 = 迟迟

- 真实受害者 / 善意联系人；
- 小时候有失踪、回来后身份错位类经历；
- 长期被论坛网络监测；
- 后期帮助玩家检查 α/β/γ 与管理员记录逻辑；
- 不能变成全知解谜 NPC，只能基于玩家实际发给她的材料判断。

## 9. 余晴（YQ）

- 现实外围引诱者；
- 负责长期建立信任、约见和失踪前现实行程；
- 不需要再硬造论坛核心小号；
- 不负责深层经文解释。

## 10. 照骨

- 无相还真会共享监测账号；
- 不对应某一个固定微信联系人；
- 用于论坛筛查、观察等级调整等工作。

# 第三部：易舍、再舍、对契

## 11. 基本规则

### 11.1 易舍必须是两个活体之间的双向交换

易舍不是死者复活、单向夺舍或灵魂复制。

它必须发生在两个活着的“舍”之间，两名“客”互换位置。

### 11.2 舍与客

- **舍**：身体；
- **客**：占据、使用身体的连续主体 / 魂。

名字和社会身份主要绑定身体与社会关系，不是易舍的超自然物理钥匙。

### 11.3 2004 第一次易舍

执行前：

- A + α：沈妍身体 + 原沈妍客；
- B + β：林楠身体 + 原林楠客。

执行后：

- A + β；
- B + α。

两边都被送回原身体对应的家庭和社会关系。

### 11.4 2026 第二次再舍

引入成年候舍：

- B + α：林楠身体 + 已稳定约 22 年的 α；
- C + γ：19-07 身体 + 候舍信徒 γ。

再舍后：

- B + γ；
- C + α；
- A + β 不参与这次交换。

### 11.5 为什么沈妍会异常

α 与 β 是 2004 年旧对契两端。

当 α 在 2026 年再次移动时，旧对契重新活跃，A + β 出现：

- 梦境；
- 旧屋空间识别；
- “楠楠”称呼反应；
- 记忆与情绪回流；
- 同步值异常升高。

这就是：

> **再舍者，故门有声。**

沈妍出现的是 β 自己作为林楠时的童年记忆，不是“原沈妍记忆回到身体里”。

## 12. 返契

返契是组织对重新活跃的旧对契进行稳定、强化、控制和观察。

返契**不等于再做一次完整易舍**。

沈妍被归入“返契异常控制”体系，是因为她是旧对契异常端，不是因为组织缺身体。

# 第四部：无相还真会与候舍制度

## 13. 无相真君

无相还真会几十年的实验不是为了研究换魂本身。

最终宗教目标：

> **证明“客”能够脱离固定之舍长期存在，并建立可供无相真君持续降舍、再舍的稳定体系。**

教内认为：

> **真君无相，不应有定身。**

本作不回答：

- 无相真君最初是谁；
- 真君是否真的从古代连续存在；
- 真君究竟是同一客还是继承的宗教身份。

玩家只需确认：现代组织确实在为“真君连续再舍”做长期验证。

## 14. 实验历史

### 14.1 早期低龄强制样本

2004 版规范：

> **低龄强制样本优先，适用 7—11 岁。**

当时组织错误认为低龄对象社会身份尚未完全固化，易舍后异常更容易被解释成失踪创伤。

沈妍与林楠属于这一阶段。

### 14.2 2012 前后改为成年候舍

长期样本证明年龄不是必要条件，组织转向：

- 对契匹配；
- 生理适配；
- 客的长期稳定；
- 身份重建；
- 候舍者主动配合。

停止“低龄优先”，把成年自愿候舍纳入正式体系。

这不是组织变善良，而是找到更稳定、更低风险、更可规模化的身体来源。

## 15. 候舍库

当前后台固定数据：

- 在库：164；
- 匹配可用：37；
- 待执行：12；
- 再舍申请：8。

候舍库不展示真实姓名，以编号作为有效身份，例如：

`24-11 / 21-16 / 19-03 / 22-08 / 23-14 / 18-02 / 19-07`

### 15.1 去名训练

- 停止使用原名；
- 不看旧照片；
- 减少与原家庭、伴侣、朋友接触；
- 日常问询只对候舍编号作答；
- 完成后移除姓名字段。

目的不是“名字有魔法”，而是削弱对原人生的依附。

### 15.2 候舍者是真正狂热信徒

口径可以直接、不舒服：

> **选我。现在就做。我不要这具身体。谁进来都行。**

> **普通客也行，真君更好。别再让我醒回这具舍里。**

> **编号就够了。旧照片、住址、关系都清掉。**

他们是主动奉舍者，不是普通医学志愿者。

## 16. 为什么有候舍还抓沈妍

必须区分：

- **候舍**：现代主动提供身体的信徒；
- **旧契样本**：历史成功易舍并长期稳定的稀缺对象；
- **论坛筛查对象**：疑似历史异常、身份错位的人。

固定口径：

> **候舍来源充足，无需强制补充。**
>
> **旧契样本不可替代，出现同步、返契异常时优先回收。**

所以沈妍被抓是因为旧对契在 α 第二次再舍后出现异常，不是因为缺身体。

## 17. 归真序列

当前后台：

> **归真序列 · 阶段 II**

核心前置验证：`RS-2026-1012`。

组织需要的是一个已经稳定约 22 年、再进行第二次迁移的长期客样本；这个时间条件无法靠增加候舍数量加速。

真君序列当前暂缓，等待长期客验证结果。

# 第五部：经文、旧教文本与视觉材料

## 18. 《百舍偈》

必须保留。

固定可辨认旧誓：

> **身非我身，名非我名。**

它是宗教 / 身份剥离语言，不是姓名超自然机制。

当前玩法用途：

1. 本地缓存旧教页中的重要文字；
2. 后期管理员兼容认证的旧誓。

## 19. 《三门疏》

四句核心文本锁死：

> **身为舍，魂为客。**  
> **形可易，忆可乱。**  
> **二客相契，两门相应。**  
> **再舍者，故门有声。**

当前私密记录中另保留一句：

> **客不可凭一门自证。**

它是抄本附句，不取代、拆分或改写上述四句。

正确是“再舍者，故门有声”，**“故梦有声”废弃**。

“故门有声”不是独立后台模块名，而是旧教对“再舍后旧对契产生反应”的表达。

## 20. 对契旧说

必须保留：

> **同庚同辰，乃天定之契。**

它是早期对高匹配对象的宗教化理想表达，不是现代所有易舍必须严格同年同月同日的硬条件。

现代组织将筛选技术化为：对契、匹配度、血样、生理适配、候舍编号等。

## 21. 仪式材料

继续保留：

- 门 / 两门 / 验门 / 门形印记；
- 红蜡烛；
- 黄纸朱砂符；
- 红线；
- 纸偶；
- 血样；
- 香灰、旧瓷碗；
- 梦境、旧屋、旧称呼、记忆回流。

固定现行短句：

> **赤烛引客，黄符镇舍。**

固定祝号：

> **舍身无量。**
>
> **无相还真，舍身无量。**

废弃：

- “黄符定名”作为现行机制；
- “赤烛照舍，黄符定名”作为现行固定礼文；
- “同根同气”作为正式术语；
- “名可夺”作为易舍物理规则。

旧图片如果历史上已经存在废弃文字，可以作为“旧时代材料”保留原图，但新内容不能继续当现行真理使用。

# 第八部：三个结局

## 29. 共通规则

只保留：

> **《归家》 / 《谁是我》 / 《双归》**

**三个结局都只能在沈妍这台电脑上发生。**

## 30. 《归家》

触发：玩家查到沈妍位置并报警，但没有把 19-07 完整线作为第二对象一并提交。

确定事实：

- 被救回并重新坐在沈妍电脑前的是 **A + β**；
- 她是徐宁认识了二十多年的沈妍，但已经知道 / 怀疑自己童年回来后就不是原始登记的沈妍客；
- 她在徐宁聊天框反复输入“我到底是谁”“如果她知道以后会怎么看我”等内容，但没有发出；
- 易舍不可逆，救人不能恢复 2004 前的身体 / 客对应。

随后，仍然只在**沈妍电脑**上表现：微信弹出一个陌生账号的好友申请。

陌生账号当前显示为：

> `m_0317`

验证消息：

> **救救我。我是沈妍。你是谁？**

这里的恐怖点不是宣布“陌生账号才是真沈妍”，而是：**屏幕前已经坐着一个以沈妍身份生活二十多年的 A + β；另一个身份严重混乱的 C + α 却也在网络另一端认定自己是沈妍。**

玩家只看到这一台电脑上的冲突，不切去陌生账号所在设备。

## 31. 《谁是我》

触发：玩家报警时已经查清并提交 19-07 线。

只通过沈妍电脑上的可访问材料表现：

- `OBS_19-07_*.wav` 内部问询录音 / 自动转写；
- 19-07（C + α）在沈妍、林楠、登记身份之间混乱；
- “为什么我知道徐宁这个名字”；
- “我以前长什么样？”；
- 随后 A + β 在徐宁聊天框输入“她是不是我 / 我是不是她 / 我们到底谁是谁”。

不替玩家给出哲学意义上的“真正谁才是沈妍”。

## 32. 《双归》

触发：

- 玩家已查到 `HL-N-04`；
- 周川明确威胁“别报警”；
- 玩家选择**一个人去**，未形成有效报警保护。

### 32.1 玩家能看到的结局

三天后仍然只有沈妍电脑。

“沈妍”对梁茵说：

> 我没事。  
> 她也没事。

随后沈妍电脑上的微信收到来自“徐宁”的普通消息：

> **到了。**

最终“沈妍”开始反向引诱梁茵，并发送：

> **无相还真，舍身无量。**

### 32.2 幕后真实关系

为了让两个归来社会身份都主动保密、终止外界追查，归来的沈妍身体与徐宁身体里都必须是无相还真会信徒之客。

#### 沈妍侧

坏结局前：

- A + β：玩家认识的沈妍；
- B + γ：林楠身体中的候舍信徒 γ。

组织再进行一次双向易舍：

- A + γ：作为“沈妍”返回社会；
- B + β：真正陪徐宁长大的 β 被组织控制带走。

因此坏结局里说“舍身无量”的“沈妍”是 **A + γ**。

#### 徐宁侧

组织从成年候舍库选择一名匹配且受训的信徒客 δ，其身体记为 H。

易舍前：

- P + 徐宁客；
- H + δ。

易舍后：

- P + δ：以“徐宁”身份返回社会；
- H + 徐宁客：被组织控制并带离原社会关系。

所以《双归》的“归”指的是**两个社会身份对应的身体都回来**，不是原来的两个人安全回来。
