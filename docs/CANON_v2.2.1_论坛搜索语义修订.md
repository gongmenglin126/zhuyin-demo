# 《烛阴旧闻》CANON v2.2.1 论坛搜索语义修订

状态：**权威补充修订**  
基线：`CANON_v2.2_无相还真会宗教感与管理员线修订.md`  
生效日期：2026-08-17

> 本文件专门修订论坛搜索语义。与 v2.2 的搜索描述冲突时，以本文件为准。

## 1. 精确搜索账号名不得反向泄漏帖子正文

当玩家精确搜索某个论坛账号名（如 `旧档员-03`、`照骨`、`折柳`）时：

- 可以显示该账号本身的用户结果；
- 可以显示标题、正文、摘要、术语或归档字段**明确提到该账号名**的公开主题；
- 可以显示由该账号本人发起的公开主题；
- **不能仅因为该账号曾经在某帖回复过，就把整篇主题作为账号搜索结果返回。**

例如：`旧档员-03` 曾在林楠旧报下留下“本帖从旧索引分类恢复”的回复，这只能作为进入该账号公开发言历史后的痕迹，不能导致玩家搜索 `旧档员-03` 时直接得到林楠旧报正文。

## 2. 林楠发现链继续保持唯一自然入口

`林楠` 必须继续通过：

红铁皮盒 → 一格胶片 → 岚棉三厂 → 寻人启事 → 报刊索引 → 旧报正文

完成首次阅读发现。任何后期账号、管理员、邪教或恢复记录的搜索都不得反向提前泄漏“林楠”姓名。

## 3. 搜索设计原则

- 搜关键词：可以命中标题、正文、摘要、回复正文等自然文本。
- 搜账号：优先表现为“查这个人/账号”，不应等同于“把这个账号回复过的所有帖子全文端出来”。
- 用户主页/发言历史可以展示该账号真实留下的公开回复，但仍应避免标题本身提前暴露尚未获得的核心答案。

核心原则：**账号出现在哪里，是调查痕迹；账号搜索不等于自动获得该页面的全部内容。**
